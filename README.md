# TILA-TECH-BOT 🤖

Advanced Telegram Bot with AI, games, moderation, and premium features.

## Features
- 🤖 AI Commands (GPT, Meta AI, etc)
- 🎮 Games
- 💰 Economy System
- 🔐 Security
- 📊 Admin Commands

## Installation

```bash
git clone https://github.com/simonbeautifulmotivationalspea-ai/tila-tech-bot-.git
cd tila-tech-bot-
npm install
cp .env.example .env
npm start
```

## Configuration

Edit `.env`:
```
BOT_TOKEN=your_token
BOT_OWNER=your_id
```

## Commands

- `/ping` - Response time
- `/help` - Help menu
- `/status` - Bot status
